# Quality Review Skill

## Purpose

Review Zhang Xiangbei AI Evolution drafts before publication.

## Review Steps

1. Check whether the core judgment is clear.
2. Check whether facts and opinions are separated.
3. Check whether the draft helps ordinary readers understand the issue.
4. Check whether unsupported claims are marked.
5. Check whether tone matches Zhang Xiangbei AI Evolution.
6. Check whether the content contains privacy or security risks.
7. Produce revision suggestions and a publishability score.

## Output Format

- Overall score: 1-5
- Publishability: publish / revise / hold
- Main issues
- Suggested revisions
- Source and safety warnings
