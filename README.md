# AI Agent Skills

这是“张向北AI进化论”的 AI Agent Skills 与母稿加工系统仓库。

它不是通用提示词合集，而是研究型超级个体用于研究、写作、内容加工和信源工程的公开工作流资产。当前版本只提供可公开的简化结构，不包含私有账号、内部路径或自动化密钥。
